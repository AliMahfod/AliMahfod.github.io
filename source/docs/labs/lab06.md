## Введение

В работе выполнен полный цикл предобработки: EDA, заполнение пропусков, инженерия признаков, обработка выбросов, агрегация и метрики качества. Все шаги и графики — в ноутбуке.

## Описание набора данных

891 пассажир, 12 исходных столбцов (`PassengerId`, `Survived`, `Pclass`, `Name`, `Sex`, `Age`, `SibSp`, `Parch`, `Ticket`, `Fare`, `Cabin`, `Embarked`).

## Первичный анализ

- Первые 10 строк, типы столбцов, `describe()` для числовых признаков.
- **Пропуски:** `Cabin` — 687, `Age` — 177, `Embarked` — 2; остальные столбцы без NaN.
- **Age:** среднее ≈ 29.7, медиана = 28.0 (до заполнения).
- Гистограммы числовых признаков; **barplot** и **heatmap** пропусков (см. ноутбук).

## Обработка пропусков

| Столбец | Метод |
|---------|--------|
| **Age** | Медиана (~28 лет); затем признак **Age_group** (Child / Teen / Young / Adult / Senior) |
| **Embarked** | Мода (**S**) |
| **Cabin** | Удалён; создан **CabinLetter** (первая буква каюты, **U** = unknown) |

После imputation пропусков в рабочих столбцах не остаётся.

## Трансформация данных

| Признак | Правило |
|---------|---------|
| **Pclass** | 1→F, 2→S, 3→T (строковый категориальный тип) |
| **Title** | Из `Name` (Mr, Mrs, Miss, …) |
| **Sex_num** | female→1, male→0 |
| **FamilySize** | SibSp + Parch + 1 |
| **IsAlone** | 1, если FamilySize = 1 |

## Обработка выбросов

- **Fare:** boxplot, выбросы по **IQR** — **116** записей вне границ 1.5×IQR.
- **Fare:** winsorization (5% с каждой стороны).
- **Age:** значения выше **95-го перцентиля** ограничены (winsor-style cap).

## Агрегация и анализ

- Средняя доля **Survived** по классу: **F** ≈ 63.0%, **S** ≈ 47.3%, **T** ≈ 24.2%.
- Группировка по **Pclass** и **Sex** — таблица `survived_rate`, `mean_fare`.
- Медианный **Age** по **Embarked**.
- Сводная **выживаемость** по **Title** и **IsAlone** (`pivot_table`).
- Результат сохранён в **`titanic_cleaned.csv`**.

## Метрики качества очистки

- **100%** заполненных ячеек после обработки (без NaN в используемых полях).
- Число уникальных категорий: Pclass (3), Title (~17), CabinLetter, Age_group (5), и др. — в ноутбуке.
- **Корреляция** новых числовых признаков с `Survived` (heatmap): положительная связь `Sex_num`, `Fare`; отрицательная — `Pclass` (как число до map) не используется после F/S/T.
