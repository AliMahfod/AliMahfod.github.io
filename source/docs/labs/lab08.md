## Задача

Источник: лента [main_news](https://news.itmo.ru/ru/main_news/). Для каждой новости:

1. **Список (п. 3):** ID (число из URL), название, дата, URL → `scraped_news_data.csv`
2. **Статья (п. 4):** ID, название, дата, просмотры, текст, теги → `news_content/<id>.csv`

### Поля CSV

**`scraped_news_data.csv`**

| Поле | Описание |
|------|----------|
| Идентификатор новости | int из URL (`/news/<id>/`) |
| Название новости | заголовок из `h4` ленты |
| Дата её размещения | `datetime` / текст из `<time>` |
| URL | полная ссылка на статью |

**`news_content/<id>.csv`**

| Поле | Описание |
|------|----------|
| Идентификатор | ID новости |
| Название новости | `h1` на странице статьи |
| Дата размещения | `news-info-wrapper` → `time` (fallback: `div.time`) |
| Количество просмотров | `span.icon.eye` |
| Текст | `div.content.js-mediator-article` (fallback: `article div.content`) |
| Теги | `ul.tags a`, через `;` |

## Особенности реализации

- Пагинация: последняя страница определяется по ссылке `#` в блоке `pagination`.
- Дубликаты ID при обходе страниц отбрасываются (`dict` по ID).
- Задержка между запросами (0.2–0.8 с) — снижение нагрузки на сервер.
- Разная вёрстка статей учтена fallback-селекторами для даты, текста и тегов.
