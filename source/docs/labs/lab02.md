## Как решена задача

### 1. Создание и обработка массивов

- `create_vector()` — `np.arange(10)` возвращает одномерный массив `[0, 1, …, 9]`
- `create_matrix()` — `np.random.rand(5, 5)` создаёт матрицу случайных чисел в `[0, 1)`
- `reshape_vector()` — меняет форму `(10,)` на `(2, 5)` без копирования данных
- `transpose_matrix()` — транспонирование через `.T`

### 2. Векторные операции

NumPy выполняет операции поэлементно (векторизация): сложение (`+`), умножение на скаляр (`*`), поэлементное умножение (`*`), скалярное произведение (`np.dot`). Это быстрее и читаемее, чем циклы Python.

### 3. Матричные операции

- Умножение матриц — оператор `@` (эквивалент `np.matmul`)
- Определитель — `np.linalg.det`
- Обратная матрица — `np.linalg.inv`
- Решение СЛАУ — `np.linalg.solve(A, b)`

### 4. Статистический анализ

CSV загружается через `pandas`, затем преобразуется в `numpy`-массив. Функция `statistical_analysis()` вычисляет среднее, медиану, стандартное отклонение, min/max и перцентили. `normalize_data()` выполняет Min-Max нормализацию: `(x - min) / (max - min)`.

### 5. Визуализация

Графики сохраняются в каталог `plots/`:

- гистограмма оценок — `matplotlib.pyplot.hist`
- тепловая карта корреляции — `seaborn.heatmap`
- линейный график — `matplotlib.pyplot.plot`

## Нюансы при решении

- **Векторизация vs циклы:** NumPy-операции работают на C-уровне; явные циклы Python не нужны и замедляют код
- **Форма массива:** `reshape` и `@` требуют совместимых размерностей; ошибка формы — частая причина падения тестов
- **Типы:** скалярные функции (`det`, `dot`) возвращают Python `float`; явное приведение типа делает аннотации корректными
- **Графики в тестах:** используется `plt.savefig()` + `plt.close()`, чтобы pytest не открывал окна GUI
- **Нормализация:** при `max == min` деление на ноль; в задании такой случай не рассматривается
- **PEP-8:** имена функций в `snake_case`, импорты сгруппированы, длина строк ≤ 88 символов

```python
def create_vector() -> np.ndarray:
    """Создать массив от 0 до 9."""
    return np.arange(10)


def vector_add(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Сложение векторов одинаковой длины."""
    return a + b


def statistical_analysis(data: np.ndarray) -> dict[str, float]:
    """Статистический анализ одномерного массива."""
    return {
        "mean": float(np.mean(data)),
        "median": float(np.median(data)),
        "std": float(np.std(data)),
        "min": float(np.min(data)),
        "max": float(np.max(data)),
        "percentile_25": float(np.percentile(data, 25)),
        "percentile_75": float(np.percentile(data, 75)),
    }
```
